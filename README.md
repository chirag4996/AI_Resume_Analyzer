# AI Resume Analyzer + ATS Score
An AI-powered Resume Analyzer built with Python and Streamlit.

## Features
-Upload Resume (PDF)
-Extract Name, Email and Phone Number
-Resume Text Extraction
-ATS Score Calculation
-Matched Skills Display

## Tech Stack
-Python
-Streamlit
-PyPDF2
-Regular Expression
-NLP

## Project Structure

AI_Resume_Analyzer/
|---app.py
|---ats_score.py
|---resume_parse.py
|---skill_extraction.py
|---requirements.txt
|---README.md

## Installation
bash
pip install-r requirements.txt

## Run
bash
streamlit run app.py
